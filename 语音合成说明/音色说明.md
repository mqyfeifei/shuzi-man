# voice_type 完整解释
## 一、基础定义
`voice_type` = **音色唯一标识ID**，用来指定用哪个人声朗读文本，是火山引擎/豆包Seed-TTS接口必填参数。
对应你项目 `services.py` 里的 `speaker_id`，两套接口只是参数名不一样：
- 旧版同步TTS接口（你这段requests代码）：`audio.voice_type`
- 新版SSE流式TTS（你项目后端）：`req_params.speaker`

## 二、两种音色ID格式（对应你之前的配置）
### 1. 官方公共标准音色（长字符串，seed-tts-2.0通用）
格式：`zh_性别_音色名_版本_bigtts`
示例：
```python
# 甜美女声
voice_type = "zh_female_tianmeixiaoyuan_uranus_bigtts"
# 沉稳男声云舟
voice_type = "zh_male_yunzhou_jupiter_bigtts"
# 多情感思思
voice_type = "zh_female_shuangkuaisisi_moon_bigtts"
```
在火山引擎控制台「音色库」直接复制ID使用。

### 2. 声音复刻自定义音色（UUID格式，就是你.env里那段）
你配置里的 `e5e16078-6358-4cf5-8274-c30c73b607df` 属于**复刻音色ID**，是你上传人声训练后生成的专属音色，只能搭配 `seed-tts-2.0` 资源ID使用。
> 重点：**复刻UUID音色只能用在流式SSE接口（你项目后端），不能直接填进这段旧同步接口的voice_type**，这也是你之前合成报错的隐藏原因之一。

## 三、你两段代码参数映射对照表
### 1）你现在的 requests 同步demo（/api/v1/tts）
```python
audio = {
    "voice_type": "音色ID",  # 公共长ID，不能填复刻UUID
    "encoding": "mp3",
    "speed_ratio": 1.0
}
```

### 2）你的项目后端 services.py SSE流式接口（/api/v3/tts/unidirectional/sse）
```python
req_params = {
    "text": text,
    "speaker": settings.doubao_speaker_id, # 这里填复刻UUID e5e16078-xxx
    "audio_params": {"format": "mp3", "sample_rate": 24000}
}
```
